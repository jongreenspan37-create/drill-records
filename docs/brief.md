# Drill Recording

## Goal

Create an online app to record and track drills on several types of vessels for crew who shift from various vessels

## Features

-Logins are created by admin no sign up form.
-Allows recording of a drill (role specific)
-Allows users to see a matrix of their drills
-Allows Admin to have an overview

## Tech stack

-Uses Docker Container
-Postgres Database
-FASTAPI backend
-React Front End
